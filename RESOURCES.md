# AI NPC community resources

Updated September 24, 2026. This is the source index for the [Matrix NPC community research review](RESEARCH-AI-NPC-COMMUNITY.md), [roadmap track](ROADMAP.md#optional-ai-npc-community-research-track), [evaluation issue #14](https://github.com/School-of-the-Ancients/school-of-the-ancients-roadmap/issues/14), and [Jev decision issue #15](https://github.com/School-of-the-Ancients/school-of-the-ancients-roadmap/issues/15). Research links are inputs to a bounded experiment, not evidence that a Matrix implementation or device validation exists.

## Agent societies, skill reuse, and autonomous laboratories

- **SwarmWorld:** S. Pal, F. Y. Wang, M. J. Buehler, *SwarmWorld: Stigmergic technological evolution in societies of language-model agents* (2026). [Paper](https://arxiv.org/abs/2608.26081) · [HTML](https://arxiv.org/html/2608.26081v1) · [code](https://github.com/lamm-mit/SwarmWorld) · [architecture](https://github.com/lamm-mit/SwarmWorld/blob/main/docs/ARCHITECTURE.md) · [dataset](https://huggingface.co/datasets/lamm-mit/swarmworld-data). Candidate fixture for local observations, shared artifacts, provenance and culture-versus-isolated baselines.
- **Voyager:** G. Wang et al., *Voyager: An Open-Ended Embodied Agent with Large Language Models* (2023). [Paper](https://arxiv.org/abs/2305.16291) · [PDF supplied in this conversation](https://arxiv.org/pdf/2305.16291) · [project](https://voyager.minedojo.org/) · [code](https://github.com/MineDojo/Voyager). Curriculum, skill library and execution feedback are relevant; its generated executable skills require a different, bounded representation for Matrix.
- **Autonomous computational laboratories:** M. J. Buehler, *Artificial intelligence agents autonomously build computational laboratories that reveal design principles of hierarchical metamaterial failure* (2026, in submission). [Public research archive](https://huggingface.co/lamm-mit/MetaMaterialsDiscovery/blob/main/README.md) · [archive root](https://huggingface.co/lamm-mit/MetaMaterialsDiscovery). No public manuscript or physical validation was established in the review; treat the archive as an example of agent-built instruments and validation needs.

## Fast decisions and authored NPC control

- **Jev / TypeSafe AI:** Diogo Almeida, [Introducing System One Models & Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev) · [documentation](https://docs.typesafe.ai/introduction) · [quickstart](https://docs.typesafe.ai/introduction/quickstart) · [Choice primitive](https://docs.typesafe.ai/primitives/choice) · [known limitations](https://docs.typesafe.ai/model-jaggedness/jev-1.13) · [confidence](https://docs.typesafe.ai/confidence). Evaluate a typed selector only among legal transitions; benchmark against fixed priority and seeded utility.
- **Halo: Combat Evolved:** Bungie's [2002 GDC AI talk](https://halo.bungie.org/misc/gdc.2002.haloai/talk.html) and [design notes](https://halo.bungie.org/misc/gdc.2002.haloai/talk.html?page=12) describe readable, stimulus-driven finite-state behavior. [Halo 2's later hierarchy](https://www.gamedeveloper.com/programming/gdc-2005-proceeding-handling-complexity-in-the-i-halo-2-i-ai) is a separate reference. Use the Combat Evolved pattern as the authored baseline for the proposed FSM plus optional Jev experiment.
- **Layered RTS example:** The user reported an Astra strategic plan followed by per-squad/key-unit Jev choices roughly twice a second in StarCraft II. A primary demonstration link, code and run data were not established; [@GZhan57](https://x.com/GZhan57) is only an attribution lead. Treat cadence and performance as unverified hypotheses in [issue #15](https://github.com/School-of-the-Ancients/school-of-the-ancients-roadmap/issues/15).

## Character animation and authoring

- **Quaternius Universal Animation Library:** [original pack](https://quaternius.com/packs/universalanimationlibrary.html) · [library 2](https://quaternius.com/packs/universalanimationlibrary2.html) · [current license page](https://quaternius.com/license.html). Evaluate exact clip inventory, rig compatibility, licensing, root motion, looping and Quest cost against [Matrix character issue #14](https://github.com/School-of-the-Ancients/matrix-loading-operator/issues/14).
- **Defold example:** [3D animations example using the free Universal Animation Library](https://defold.com/llms/examples/animation/3d_animations/). A useful skinned-model reference, not Unity import or Quest evidence.
- **Rigipo Studio:** [product/download page](https://rigipo.com/download/) · [Fab listing](https://www.fab.com/listings/5d79abf2-ac69-4372-be7d-644c0dd97da5) · [creator demonstration](https://www.reddit.com/r/UnrealEngine5/comments/1wn7oht/i_made_a_texttoanimation_plugin_for_ue5_that_runs/). Vendor/creator describe offline UE5 text-to-animation, humanoid retargeting and looping. Unity export, rights and quality remain to be tested.
- **Astra-to-Blender workflow:** User-supplied proposal: generate timed stick-figure pose sequences, then create/review/bake animation in Blender and import a tested clip. No public workflow document or validated Matrix asset was supplied; the [research review](RESEARCH-AI-NPC-COMMUNITY.md#additional-candidate-inputs-character-motion-and-fast-local-decisions) records the test.

## Inhabited worlds and player-facing examples

- **World of Warcraft thought experiment:** A fictional Matrix quest hub where a quest giver remembers players, comments on repeated requests and briefly wanders, while required quests stay accessible. [Blizzard's Follower Dungeons](https://news.blizzard.com/en-gb/article/24054790/take-the-lead-in-follower-dungeons) are a real AI NPC reference, not evidence that every WoW quest giver is generative.
- **Current conversational NPC examples:** [Fortnite LLM conversations publishing announcement](https://www.fortnite.com/news/publish-islands-with-llm-conversations-starting-july-30) · [Ubisoft NEO NPC prototype](https://news.ubisoft.com/en-gb/article/5qXdxhshJBXoanFZApdG3L/how-ubisofts-new-generative-ai-prototype-changes-the-narrative-for-npcs). Compare persona control, quest authority, latency, safety and authored fallbacks.
- **Existing Matrix owner:** [Matrix NPC roadmap #29](https://github.com/School-of-the-Ancients/matrix-loading-operator/issues/29) and [first character/animation #14](https://github.com/School-of-the-Ancients/matrix-loading-operator/issues/14). This planning repo records research; Matrix owns reusable NPC runtime implementation.

## Learned shared-world comparator

- **Odyssey:** [site](https://odyssey.systems/) · [Agora-2 announcement](https://odyssey.systems/introducing-agora-2) · [Agora-2 technical report](https://agora-2.odyssey.systems/agora-2.pdf) · [public preview](https://agora.odyssey.systems/) · [Odyssey-3](https://odyssey.systems/introducing-odyssey-3) · [PROWL paper](https://arxiv.org/abs/2605.18803). Shared state and generated views are a comparator for Matrix's deterministic world, action receipts and replay. The technical report and preview remain to be evaluated; no Unity/Quest integration is inferred.
