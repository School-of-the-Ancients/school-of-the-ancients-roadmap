# School of the Ancients project index

This is a lightweight index for three products that share tools.

| Product | Home and work owner | Responsibility |
| --- | --- | --- |
| **Matrix Loading Operator** | [Matrix repository](https://github.com/School-of-the-Ancients/matrix-loading-operator) and its roadmap | Shared world runtime, Operator, creation, presentation, interaction, persistence and generic WebXR/room AR. |
| **School of the Ancients** | [School repository](https://github.com/School-of-the-Ancients/school-of-the-ancients) and its issues | Converse with historical minds; teaching, sources and learner records. Uses Matrix for presentation material. |
| **Civilization** | Citizens code currently in Matrix; [#29](https://github.com/School-of-the-Ancients/matrix-loading-operator/issues/29) | AI residents and society, Boulder and the geographic AR overlay. Uses Matrix for world capabilities. |
| **Manfred / human interface** | Its implementation project | Private human/wearable context and explicitly permitted observations. |
| **This index** | Here | Cross-project boundaries, integration notes and research pointers. |

Civilization is a separate logical module; this record does not claim that its code has been extracted or a new repository exists. School's historical guides do not require a Citizens simulation.
